# GitHub Submission

1. Within your group, choose a leader, preferably someone who has prior experience in creating GitHub repositories.

2. Every member should be able to:
- Create a repository named "testing-submission". Make sure not to include a README file during the repository creation process.
- Follow the GitHub instructions that were discussed both in class and provided.

3. Organize your project directory structure as follows:
```sh
Dev
└── week#
    ├── Frontend
    ├── Backend
    ├── Project
    └── Reflection-Journal
```

4. Team leaders, please ensure that all team members are capable of performing the following tasks:
- Creating a new repository on GitHub.
- Generating a .gitignore file when necessary, such as for excluding the node_modules folder.
- Adhering to the specified folder hierarchy for each week's work.
- Ensuring that a Reflection-Journal exists for each week's activities.

Notes:
- When composing your reflection journal, you can opt for either the [simple template](https://github.com/tx00-web/activities/tree/week2/4-reflection-journal) or the [more comprehensive version](https://github.com/tx00-web/activities/blob/week1/4-Reflection-Journal/template.md).
- Feel free to invite me to your breakout room whenever you require assistance.
- I will make an effort to visit all breakout rooms within Zoom.
